# 悬浮歌词（Android）

系统级 Spotify 悬浮歌词应用：繁体歌词自动转简体、多歌词源自动回退、QQ音乐式锁定模式。零第三方运行时依赖，无需服务器。

- 最低系统要求：Android 8.0（API 26）
- 目标 SDK：35

## 安装与授权

安装 APK 后首次打开，按 App 内引导依次授予三项权限：

| 权限 | 用途 | 授权位置 |
|---|---|---|
| 通知使用权「Spotify 播放监听」 | 读取 Spotify 播放状态与歌曲信息 | 设置 → 通知使用权 |
| 悬浮窗权限（显示在其他应用上层） | 显示桌面歌词 | 设置 → 应用 → 悬浮歌词 |
| 通知权限 | 前台服务常驻通知（保活） | 首次启动弹窗 |

## 使用

1. 打开 App，确认三项权限均已授予
2. 打开 Spotify 播放任意歌曲
3. 悬浮歌词自动出现并逐行同步
4. 点击前台服务通知可返回 App 主界面

## 悬浮窗交互

| 操作 | 效果 |
|---|---|
| 点击右上角 🔓 | **锁定**：歌词切换为单行绿字（黑描边，任意背景可读），宽度自适应，触摸完全穿透——不遮挡、不拦截底层应用的任何操作 |
| 锁定态点击 🔒 | 解锁，恢复完整卡片 |
| 拖动卡片 | 移动位置（自动记忆，重启后保持） |
| 双击卡片 | 切换多行/紧凑显示模式 |

主界面还可实时调节字号、查看当前歌词来源与本地缓存数量。

## 歌词获取

- 双源并行竞速：LRCLIB 与 QQ音乐同时请求，先成功者胜出（最快即时，最坏 8s）
- QQ 音乐搜索四链路降级：局域网代理 → 网页搜索 → 桌面端点 → smartbox 搜索建议（前两者已被 QQ 封锁时 smartbox 仍可用）
- 歌手感知匹配：歌名相等（大小写/繁简不敏感）+ 歌手兼容（双向包含）+ 时长接近辅助；同名不同歌手/纯时长相近的歌曲会被拒绝（防止显示错误歌词）
- 网络类失败（接口频控/断网）20 秒后自动重试；曲库确认无结果不重试
- 繁体歌词经内置词典转换为简体后显示
- 已播放歌曲的歌词本地缓存，重复播放不再发起网络请求
- 纯音乐/无人声曲目无歌词属正常现象

## 歌词代理（可选，推荐）

QQ音乐搜索接口被封锁时，手机与电脑连同一 WiFi 可复用电脑端 qqProxy 的持久缓存：

- 主界面「设置 → 歌词代理」填入电脑地址（如 `http://192.168.5.8:39871`），点「保存」并「测试」
- 电脑端需运行 qqProxy（计划任务 SpotifyQQProxy 开机自启）
- 手机离开该 WiFi 后代理自动熔断 5 分钟（快速回退直连，不拖慢搜索），回到 WiFi 自动恢复

## 同步诊断

主界面「同步诊断」卡片逐层显示同步链路状态，用于定位「悬浮歌词没跟上 Spotify」：

- **通知监听**：系统层是否连接（未连接 = 收不到任何播放状态）
- **Spotify 会话**：是否已绑定（未绑定 = 打开 Spotify 播放任意歌曲即可触发）
- **最近播放事件**：最后一次收到播放状态的时间

「通知监听」未连接时点「重新连接」请求系统重绑；仍无效则去系统设置把「通知使用权」关闭再重新开启（App 更新后常见），MIUI 等国产系统还需允许本应用自启动与后台运行。

## 歌词校准与刷新

- **自动**：播放进度快照每 2 秒自动回正（进度漂移自愈）
- **手动校准**：主界面「歌词校准」调节偏移——歌词偏快按「+」（延后显示），偏慢按「-」（提前显示），步进 0.5s/1s，可重置；调整后 500ms 内生效
- **手动刷新**：正在播放卡片右上「重新获取」清当前曲缓存并立即重新搜索（歌词源更新或首次失败时使用）

## 常见问题

**悬浮窗不出现？**
依次检查：悬浮窗权限已授予 → Spotify 正在播放 → 通知使用权已授予「Spotify 播放监听」。若刚安装/更新过 App，在系统设置的「通知使用权」中关闭再重新开启一次该权限。

**歌词不同步？**
歌词进度取自 Spotify MediaSession，受网络与 Spotify 缓冲影响可能有 1 秒内偏差；切歌瞬间同步会自动重建。

**Spotify 后台被杀后歌词消失？**
本 App 依赖 Spotify 的 MediaSession，Spotify 进程被系统清理后无法获取播放状态，重新打开 Spotify 播放即可恢复。

## 从源码构建

```powershell
.\gradlew.bat assembleRelease
# 产物: app/build/outputs/apk/release/app-release.apk
.\gradlew.bat :core:test   # 运行 LRC 解析/繁简转换单元测试
```

要求 JDK 17+ 与 Android SDK 35。Release 构建默认使用 debug 密钥签名以便直接分发，正式分发请替换 `app/build.gradle.kts` 中的 `signingConfigs`。
